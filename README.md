## 🤖 استخدام الذكاء الاصطناعي

تم تطوير هذا المشروع **بمساعدة الذكاء الاصطناعي (AI)** كأداة مساعدة أثناء عملية التطوير.

استخدمت الذكاء الاصطناعي في بعض مراحل المشروع، مثل:

* 💡 اقتراح أفكار للتصميم والواجهة
* 🧩 المساعدة في كتابة وتنظيم بعض الأكواد
* 🎨 تحسين وتنسيق تصميم CSS
* ⚙️ المساعدة في تطوير بعض وظائف JavaScript
* 🐛 المساعدة في اكتشاف الأخطاء وإصلاحها
* ✨ اقتراح تحسينات على تجربة المستخدم والواجهة
* 📝 المساعدة في كتابة وتنظيم محتوى المشروع

> **الذكاء الاصطناعي كان أداة مساعدة في عملية التطوير، وليس بديلاً عن التعلم أو فهم الكود. تم تعديل ومراجعة الأكواد والأفكار بما يتناسب مع احتياجات المشروع.**
